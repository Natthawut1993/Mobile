Business Problem

ปัญหาที่เรากำลังแก้

ธุรกิจต้องการหาตัวแทนจำหน่ายน้ำมันพืชจาก Ads แต่เมื่อคนทักเข้ามามาก Admin คนเดียวต้องเสียเวลาอ่านทั้งคนที่พร้อมซื้อและคนที่เพียงสอบถามข้อมูล

01

แชทเยอะ ≠ Lead ดี

จำนวน Conversation สูงไม่ได้แปลว่าจะเกิดตัวแทนหรือ First Order สูงตาม

02

Admin กลายเป็นคอขวด

03

วัดผลไม่ถึงยอดซื้อ

ถ้าวัดแค่คนทัก จะยังไม่รู้ว่า Ads ชุดไหนสร้างตัวแทนที่ซื้อจริง

Qualification Logic

HOT / WARM / COLD อยู่ที่ไหนในระบบ?

ใน Pilot ไม่จำเป็นต้องมี “Lead Score 95/100” แบบระบบที่เขียนเอง เราใช้คำตอบจาก Smart Flow ให้ ZWIZ ติด Tag และ Status ซึ่ง Admin สามารถค้นหาและจัดกลุ่มลูกค้าได้จริง

Product: ZWIZ ChatbotFeature: Tag + Status + Smart FlowPilot: ไม่ต้องเขียนโค้ด
● HOT

ส่งให้ Admin ก่อน

ตัวอย่าง: ร้านขายส่ง + 50+ ลัง + พร้อมภายใน 7 วัน + ขอราคา

ZWIZ ทำอะไร: Flow ติด Status = HOT และ Tags ตามคำตอบ เพื่อให้ Admin ค้นหา/แยกกลุ่ม
● WARM

Follow-up ต่อ

ตัวอย่าง: สนใจ 6–20 ลัง หรือพร้อมภายใน 1 เดือน แต่ยังต้องการข้อมูลเพิ่ม

ZWIZ ทำอะไร: ติด Status = WARM และใช้ Follow-up / Broadcast ตามเงื่อนไขที่เหมาะสม
● COLD

Bot ดูแลก่อน

ตัวอย่าง: ยังศึกษาข้อมูล ปริมาณน้อย และยังไม่มีช่วงเวลาที่พร้อมเริ่ม

ZWIZ ทำอะไร: เก็บ Tag/Status ไว้ ไม่ดันขึ้นคิวเร่งด่วนของ Admin
แล้ว Lead Score 95 ที่เห็นก่อนหน้านี้ล่ะ? นั่นคือ Concept เพื่ออธิบายการจัดลำดับ ไม่ใช่หน้ามาตรฐานที่ยืนยันว่ามีใน ZWIZ เราจึงเปลี่ยน Proposal ให้ใช้ Tag/Status ซึ่ง ZWIZ รองรับจริง ก่อน หากอนาคตต้องการคะแนนตัวเลขค่อยประเมิน Custom Logic/API เป็น Phase 2
